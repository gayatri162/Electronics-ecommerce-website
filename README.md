# 🛒 TechStack - Electronics E-Commerce Website

TechStack is a full-stack electronics e-commerce web application. The platform allows users to browse electronic products, view product details, manage their shopping cart, and enjoy a responsive shopping experience.

## 🚀 Features

-  User Authentication
-  Browse Electronic Products
-  Product Details Page
-  Shopping Cart functionality
-  Checkout Page
-  Responsive User Interface
-  Backend integration using Flask
-  MongoDB Atlas database integration
-  Deployed on Render

---

## 💻 Installation

### Clone the repository

```bash
git clone https://github.com/gayatri162/Electronics-ecommerce-website.git
```

### Navigate to the project directory

```bash
cd Electronics-ecommerce-website
```

### Install dependencies

```bash
cd backend
pip install -r backend/requirements.txt
```

### Run the application

```bash
python backend/app.py
```
